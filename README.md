# Event Management System

A full-stack Event Management System built using React and Spring Boot.

## Features

### User Features

- User Registration
- User Login
- JWT Authentication
- View Available Events
- Register for Events
- View My Registrations
- Cancel Event Registration
- Duplicate Registration Prevention
- Event Capacity Validation

### Admin Features

- Admin Login
- Create Events
- Update Events
- Delete Events
- View All Events

## Tech Stack

### Frontend

- React
- Vite
- JavaScript
- CSS

### Backend

- Java
- Spring Boot
- Spring Data JPA
- JWT Authentication
- Maven

### Database

- PostgreSQL

## Authentication

The application uses JWT-based authentication. After successful login, a JWT token is generated and used to identify the currently logged-in user.
